# Kim Yeonjae / 김연재

Software engineer building reliable services with Java/Spring, PostgreSQL/Redis, Kubernetes, and observability.

I work from user-facing features through deployment and operating conditions. I prefer reproducible claims: define the failure, choose the smallest adequate tool, verify the result, and document the remaining limit.

## Focus

- **Backend reliability** — concurrency control, data integrity, domain boundaries, and performance work backed by integration tests or measured outcomes.
- **Service operations** — CI/CD, metrics, logs, traces, backup validation, and recovery-minded design.
- **Systems learning** — a personal learning and operations environment for four services; it is not represented as commercial IDC experience.
- **AI & data** — asynchronous collection, speech-to-text, LLM structuring, schema validation, and explicit quality limits.
